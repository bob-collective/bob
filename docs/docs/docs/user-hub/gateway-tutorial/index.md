# How to use Gateway

Gateway swaps between native Bitcoin, stablecoins, wrapped Bitcoin, tokenised gold and more across multiple chains — in a single transaction. Powered by Bitcoin intents, built by BOB.

This tutorial walks through each flow end to end. Pick the one that matches what you're holding.

- **[Swap tokens for native Bitcoin](./evm-to-btc/)** — you hold USDT, USDC or another supported token and want BTC.
- **[Swap native Bitcoin for tokens](./btc-to-evm/)** — you hold BTC, in a wallet, on an exchange, or on a hardware device.
- **[Swap between EVM chains](./evm-to-evm/)** — move USDT, USDC, ETH and other tokens across chains.

## What you can swap

Routes are added regularly. For the live list of chains and assets Gateway supports right now, see [Supported routes](https://docs.gobob.xyz/gateway/supported-routes).

## Wallets

**On the EVM side**, Gateway supports 500+ wallets through [Reown AppKit](https://reown.com/appkit), including MetaMask, OKX, Rabby, Coinbase Wallet and Binance Web3 Wallet.

**On the Bitcoin side**, all the major wallets are supported — Xverse, Unisat, OKX, Leather, Bitget, Binance Web3 Wallet and Phantom among them. Every standard Bitcoin address type is accepted: Legacy, SegWit, Native SegWit and Taproot.

You don't always need a Bitcoin wallet connection. Where BTC is the asset you receive, pasting an address is enough — including a hardware wallet address or an exchange deposit address. Where BTC is the asset you spend, you can either connect a wallet or pay by sending to an address Gateway gives you.

## How long it takes

Bitcoin block confirmations set the pace. Most orders involving BTC complete in around 10 minutes, though this varies with Bitcoin block times. Swaps between EVM chains usually settle within a couple of minutes.
